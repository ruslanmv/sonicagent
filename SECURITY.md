# Security policy

Report vulnerabilities through GitHub private vulnerability reporting. Do not open a public issue for suspected vulnerabilities. Batch speech runs, and the realtime gateway is not a production deployment. The development token is not safe on a public network.

Before deployment, implement short-lived session tokens, TLS, origin validation, rate limiting, payload limits, queue bounds, tenant isolation, secure model downloads, checksum verification, redaction, secret management, dependency scanning, container hardening, and incident runbooks.
