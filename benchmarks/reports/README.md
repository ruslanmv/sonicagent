# Benchmark reports

Published measurements live in this directory. Generated probe output under `benchmarks/results/` stays out of Git.

The current HTTP pass is [hf-cpu-basic-endpoint-capability.md](hf-cpu-basic-endpoint-capability.md). It records one Linux client calling the Hugging Face Space. It is not a Quest, phone, or glasses test, and it is not a service level.

`make benchmark-smoke` writes placeholder timings. Do not quote that command as speech latency.
